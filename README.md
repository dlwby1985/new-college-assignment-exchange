# New College Assignment Exchange

A demonstration of a faculty assignment-sharing hub, prepared by Baoyu Wang for project discussions.

The page uses a snapshot of 88 assignment records. Search, filters, sorting, and resource details work locally; saved favorites remain in the visitor's browser. Contributor names, activity counts, and adaptation interactions are illustrative. ASU authentication, live Airtable synchronization, Canvas export, and shared discussions are not connected.

This is a project prototype, not an official ASU service or a production deployment. The longer-term goal is an ASU-supported faculty hub with attribution, linked adaptations, and community interaction.

The original prototype is preserved separately. This publication copy adds standard HTML metadata and clarifies demonstration status.
